# LITTLE NO

**v1.0.0**

A dumpling walks forward forever. You never steer it. Look at the room. Change one thing.

LITTLE NO is a one-thumb puzzle platformer: a squishmallow dumpling with a pink bow and a lollipop walks on its own. Tap fans, boards, lids, magnets, and belts so it reaches **OUT**. One hundred rooms across kitchen, winter, jungle, and summer — glossy candy art, logical puzzles, not mash-clicking.

## Play

```
npm install
npm run dev
```

Open the local URL, tap **Play**. Progress is saved in the browser.

## What’s in v1

- 100 unique rooms (kitchen, winter lodge, jungle lodge, summer lodge)
- Undo, restart, pause, stars
- Squishmallow dumpling, pink bow, swirl lollipop
- Candy Crush–style glossy rooms
- Mobile portrait layout

## Controls

Tap what you want to change. Never tap the dumpling.
